# Consubov

A monorepositório Consubov com aplicações web e API, packages de domínio, e integração com Supabase.

## Development

Working locally? You need Bun — [install with nvm](https://github.com/typed/bun#installing-and-updating).

```sh
bun install
bun run dev
```

## Available scripts

- `dev` — start development server with Turborepo
- `build` — build production assets
- `lint` — lint all packages
- `test` — run tests with Vitest
