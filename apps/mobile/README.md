# CONSUBOV Mobile — workspace experimental congelado

> **Status desde 2026-10-07:** este workspace Capacitor/WebNative está **congelado**. A direção mobile vigente do CONSUBOV é **PWA mobile-first** sobre `apps/web` para iOS e Android.

Não expandir adapters nativos, plugins ou empacotamento nesta etapa.

O empacotamento nativo só deve ser reavaliado depois que a Web/PWA estiver em produção, com fluxos críticos 100% funcionais e offline/sync estabilizado, e apenas se existir necessidade comprovada de loja ou capability gap.

Referências vigentes:

- `CONSUBOV_INSTRUCOES_MESTRE_PROJETO.md`;
- `CONSUBOV_CHECKLIST_MESTRE.md`;
- `docs/30-pwa-mobile-first.md`.

O código atual pode permanecer como experimento histórico/reversível, mas não é fonte de verdade arquitetural e não deve orientar novas implementações.
